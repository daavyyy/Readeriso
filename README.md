# Readeriso

**Leia. Escreva. Compartilhe.**

O Readeriso é uma plataforma web voltada para leitores e escritores, criada com o objetivo de aproximar pessoas por meio da literatura. A proposta é oferecer um espaço onde os leitores possam descobrir histórias e os escritores tenham a oportunidade de criar, organizar e compartilhar suas próprias obras.

## ✨ Funcionalidades

- 📖 **Explorar histórias:** descubra obras e encontre novas leituras.
- ✍️ **Área de escritor:** crie histórias, escreva capítulos e organize suas produções.
- 📝 **Rascunhos:** salve histórias em andamento para continuar escrevendo depois.
- 📚 **Biblioteca:** acesse as histórias publicadas na plataforma.
- 🔎 **Busca e descoberta:** encontre conteúdos de interesse.
- 🌐 **Sites literários:** conheça plataformas e recursos úteis para leitores e escritores.
- 👤 **Autenticação:** páginas de cadastro e login para acesso às funcionalidades da plataforma.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** funcionalidades e interatividade.
- **Bootstrap 5.3.8:** componentes e recursos de interface.

## 🎨 Identidade visual

O Readeriso utiliza uma identidade visual minimalista, com predominância de preto e vermelho. A interface busca proporcionar uma experiência agradável, organizada e intuitiva, valorizando tanto a leitura quanto a escrita.

## 🎯 Objetivo do projeto

O Readeriso busca incentivar a leitura, estimular a escrita criativa e facilitar o acesso a histórias e recursos literários. A plataforma está sendo desenvolvida como um projeto web, com foco na experiência dos usuários e na construção de um ambiente dedicado à comunidade literária.

## 👥 Equipe de desenvolvimento

Projeto desenvolvido por estudantes, com apoio de ferramentas de pesquisa, documentação e inteligência artificial durante o processo de desenvolvimento.

## 📌 Status do projeto

**Em desenvolvimento.**

Novas funcionalidades, melhorias visuais e ajustes de funcionamento poderão ser adicionados ao longo do desenvolvimento.
